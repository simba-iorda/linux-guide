Linux — система на много людей. Чтобы Петя не испортил файлы Маши, у каждого файла есть **владелец**, **группа** и **набор прав**.

## Как читать ls -l

Вывод `ls -l` начинается с загадочной строки из десяти символов:

```
-rwxr-xr--  1 alice devs 4096 Sep 23 10:00 script.sh
```

Разберём её:

- первый символ — тип: `-` файл, `d` папка, `l` ссылка;
- дальше три тройки: права **владельца**, **группы** и **остальных**;
- в каждой тройке `r` — читать, `w` — писать, `x` — выполнять.

У нас `rwxr-xr--` значит: владелец может всё, группа — читать и выполнять, остальные — только читать.

## Числа вместо букв

Три права удобно закодировать цифрами: `r` = 4, `w` = 2, `x` = 1. Просто складываем:

| Число | Права | Смысл |
|:---:|---|---|
| 7 | `rwx` | всё |
| 6 | `rw-` | читать и писать |
| 5 | `r-x` | читать и выполнять |
| 4 | `r--` | только читать |
| 0 | `---` | ничего |

Отсюда классические комбинации: `644` для обычных файлов, `755` для скриптов и папок, `600` для секретов.

## Команда chmod

```bash
chmod 755 script.sh      # числовой способ
chmod +x script.sh       # просто добавить право на запуск
```

Обрати внимание: `chmod +x` добавляет право на выполнение **всем** — это общепринято и удобно для скриптов.

## Владелец файла

```bash
chown alice file.txt         # сменить владельца
chown alice:devs file.txt    # владельца и группу сразу
```

Сменить владельца может только root — это логично, иначе любой мог бы переписать себе чужие файлы.

> 💡 Для папки права означают другое: `x` — право **войти** в неё и обращаться к файлам. Папка без `x` выглядит «нечитаемой», даже если у неё есть `r`.
