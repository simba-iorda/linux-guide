Весь Linux — это одно дерево папок. Не «диск C и диск D», а один корень `/`, от которого растут все ветки. Флешка, второй диск, сетевой ресурс — всё куда-то прирастает внутрь этого дерева.

## Где я сейчас

Чтобы не заблудиться, спроси у системы, где ты:

```bash
pwd
```

`pwd` расшифровывается как *print working directory* — «покажи рабочую папку». Рабочая папка — твоя текущая позиция. От неё считаются все относительные пути.

## Специальные адреса

| Запись | Что значит |
|---|---|
| `/` | Корень, начало всех путей |
| `~` | Твоя домашняя папка (`/home/user`) |
| `.` | Текущая папка |
| `..` | Папка уровнем выше |
| `-` | Предыдущая папка (для `cd -`) |

Абсолютный путь начинается с `/` и работает откуда угодно. Относительный считается от текущего места: `../logs` — «подняться на уровень и зайти в logs».

## Куда пойти

```bash
cd /etc        # уйти в /etc по абсолютному пути
cd ..          # на уровень выше
cd ~           # в домашнюю папку (то же, что просто cd)
cd -           # вернуться туда, откуда только что пришёл
```

> 💡 `cd` — одна из немногих команд, у которой нет вывода. Если после неё ничего не произошло — значит, всё сработало.

## Что здесь лежит

```bash
ls             # список файлов в текущей папке
ls -l          # то же, но с подробностями
ls -a          # показать ещё и скрытые файлы (они начинаются с точки)
tree           # красивое дерево вложенных папок
```

## Главные папки системы

| Папка | Что там |
|---|---|
| `/etc` | Настройки системы и программ |
| `/home` | Домашние папки людей |
| `/var` | Изменяемые данные: логи, кэши |
| `/tmp` | Временные файлы, стираются при перезагрузке |
| `/bin` | Программы |
| `/dev` | Устройства, которых система тоже считает файлами |
