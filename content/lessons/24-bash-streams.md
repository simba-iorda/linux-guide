## Зачем это тебе

Бывает, что команда вывела полезные данные и отдельную ошибку. Их можно сохранить в разные файлы и проверить код выхода.

## Как это работает

У команды есть обычный вывод `stdout` и диагностический поток `stderr`. Оператор `>` записывает обычный вывод, а `2>` направляет диагностику в файл. `>>` дописывает в конец. `<` берёт ввод из файла.

```bash
cat notes.txt missing.txt > notes-copy.txt 2> errors.txt
```

В Bash `$?` хранит код выхода последней команды. Успех обычно даёт 0. У `grep` код 1 означает, что совпадений нет, а код 2 — ошибку. Введи команду, затем отдельной строкой `echo $?`.

`&&` выполняет следующий шаг при успехе предыдущего, `||` — при неуспехе. Пайп передаёт обычный вывод. `sort` сортирует строки, а `uniq` убирает соседние дубликаты.

```bash
sort jobs.txt | uniq > unique.txt
```
