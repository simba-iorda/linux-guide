Иногда нужно быстро ответить на вопросы: что за система, сколько памяти, сколько места на диске, какой сегодня день. Всё это — несколько коротких команд.

## Что за система

```bash
uname -a              # имя ядра, версия, архитектура
date                  # текущие дата и время
```

`uname` расшифровывается как *unix name*. С флагом `-a` (all) он выводит всё разом: ядро, машину, процессор.

## Сколько памяти

```bash
free -h
```

`free` показывает оперативную память и swap. Флаг `-h` включает «человеческие» единицы: гигабайты и мегабайты вместо байтов.

Важно понимать одну вещь: **мало свободной памяти — это нормально**. Linux использует простаивающую память под кэш диска и мгновенно отдаёт её, если понадобится. Смотри на столбец *available* — сколько реально доступно.

## Сколько места на диске

```bash
df -h
```

`df` = disk free. Показывает по каждому разделу общий объём, занятое и свободное место. Если место кончается, именно сюда смотрят первым делом.

## Мелочи, которые пригождаются

```bash
echo $HOME     # путь к домашней папке
whoami         # текущий пользователь
```
