Команды забываются — это нормально. Настоящие профессионалы тоже подглядывают. Главное знать, **где** подсмотреть.

## Справка прямо в терминале

Почти у каждой команды есть встроенная инструкция. Открывается она командой `man` (manual — руководство):

```bash
man ls
```

Внутри: стрелки или пробел — листать, `/слово` — искать по тексту, `q` — выйти. Если `man` кажется тяжеловесным, есть короткий вариант:

```bash
ls --help
```

Для самых забывчивых есть `help` — список команд самого тренажёра.

## Полезные мелочи на старт

| Команда | Что делает |
|---|---|
| `whoami` | Показать, под каким пользователем ты работаешь |
| `date` | Текущая дата и время |
| `history` | Все команды, которые ты уже вводил |
| `clear` | Очистить экран (или `Ctrl+L`) |

`history` — недооценённая вещь. Не помнишь, какую длинную команду запускал полчаса назад? Открой историю и найди её. А ещё в настоящем терминале есть `Ctrl+R` — поиск по истории: начни печатать и bash подскажет.

> 💡 `whoami` отвечает на вопрос «кто я по мнению системы». Обычный пользователь работает без полных прав — это защита от случайной поломки, а не ограничение свободы.
