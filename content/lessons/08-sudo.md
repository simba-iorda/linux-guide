В Linux нет «главного пользователя на каждый день». Есть обычные пользователи и есть отдельный администратор — **root**.

## Зачем разделять

Когда ты сидишь под обычным пользователем, ты не можешь случайно стереть системные файлы или сломать настройки. Это не недоверие к тебе — это защита от ошибки. Опечатка в команде под root может стоить выходного дня.

## sudo — «сделай это от администратора»

Когда разово нужны полные права, перед командой ставят `sudo` (superuser do):

```bash
sudo dnf install nano     # установка программы от root
sudo whoami               # покажет root
```

После `sudo` система спросит **твой** пароль (не пароль root) и на несколько минут запомнит, что ты уже подтверждал права.

Кто вообще имеет право на `sudo`, описано в настройках — обычно пользователи из группы `sudo` (в Fedora/Red Hat группа называется `wheel`).

## Кто я и кто есть ещё

```bash
whoami       # под каким пользователем я сейчас
echo $USER   # то же, но через переменную окружения
id           # подробно: UID, основная группа, все группы
```

Файлы, где всё это хранится: `/etc/passwd` — список пользователей, `/etc/group` — группы, `/etc/shadow` — хэши паролей (его читает только root).

> 💡 `sudo` пишет в системный лог, что и когда было сделано от root. Это удобно для разбора: видно, кто и что менял.
