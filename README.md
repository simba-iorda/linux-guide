# Linux за 2 месяца

> ⚠️ **Экспериментальный проект, полностью сделанный ИИ.** Весь код и все тексты
> курса сгенерированы ИИ-агентами (см. «Стек и как это делалось»); человек ставил
> задачи и принимал результат. Корректность работы и точность фактов **проверены
> лишь частично** — возможны ошибки, неточности и недоработки. Используй с
> критическим мышлением: не запускай команды на своей системе, если не понимаешь,
> что они делают (это, впрочем, и есть первый урок курса). Нашёл ошибку — создай
> issue или PR.

Интерактивный курс по основам Linux в виде одного полноэкранного терминала.
Офлайн-совместимый, без фреймворков и сборки.

Курс: 8 модулей × 5 уроков, 40 уроков, ~30 минут в день. Контент основан на
шпаргалке [Linux-](https://github.com/justxor/Linux-) (MIT) и переработан ИИ в
учебный формат.

## Как запустить

Сайт работает только через HTTP (fetch не умеет `file://`). Самый простой способ:

```bash
./start.sh
```

Или вручную:

```bash
python3 -m http.server 8000 -d ~/linux-tutorial
```

После запуска открой в браузере:

```
http://localhost:8000
```

## Как это устроено

- **Один полноэкранный терминал**: Catppuccin Mocha по умолчанию, JetBrains Mono
  везде, лигатуры, лёгкая прозрачность, отступы 10 px. Весь интерфейс — строки
  вывода в едином скроллбэке, без веб-панелей и карточек.
- **Навигация командами**: `помощь`, `курс`, `урок <номер>`, `дальше`, `назад`,
  `тема список|<имя>`, `shell bash|fish|zsh`, `сброс`.
- **Урок = сессия терминала**: заголовки секций — как `# комментарий`, текст — как
  stdout, код-блоки — терминальные строки. Новый урок печатается в общий поток.
- **Квизы в том же промпте**: `[?] вопрос` с вариантами `a)`, `b)`, `c)`; ответ —
  буква в общей командной строке; верно/неверно + объяснение.
- **Terminal-задачи в том же промпте**: `# задача: …`, команды уходят в симулятор,
  проверки после каждой команды, успех — строка `Задача выполнена ✓`. Команды
  `подсказка` и `решение` печатают подсказку и решение.
- **Симулятор терминала**: режимы bash/fish/zsh, ghost-автоподсказка в fish,
  история команд, автодополнение по Tab.
- **Прогресс и темы** сохраняются в `localStorage`; при повторном визите курс
  открывается на последнем месте.
- **8 тем**: Catppuccin Mocha/Macchiato/Frappé/Latte, Dracula, Nord, Gruvbox Dark,
  Tokyo Night — переключение через команду `тема`.

- Иконки — inline SVG/Nerd-глифы не используются, эмодзи Unicode

**Контент**

- 40 уроков в 8 модулях на русском (Markdown + front-matter + JSON-блоки
  `quiz`/`terminal`)
- Исходная шпаргалка: [justxor/Linux-](https://github.com/justxor/Linux-) (MIT)
- Полная копия шпаргалки — «Полный справочник» внутри курса

**Инфраструктура**

- GitHub Pages + GitHub Actions (деплой статики, `.nojekyll`)
- Локальный запуск: `python3 -m http.server`
- SSH-deploy, git

## Стек и как это делалось (ИИ)

Проект целиком произведён ИИ-агентами в [OpenCode](https://opencode.ai):

- **Оркестратор** — планирование, декомпозиция, интеграция, валидация
  (модель GLM от Z.ai)
- **Специализированные суб-агенты**: дизайнер (UI/UX терминала), исполнители
  (контент и код), исследователь (документация GitHub)
- **Человек** — владелец репозитория: формулировал требования по ходу,
  отбирал решения, тестировал руками
- E2E-проверки: Node-скрипт прогоняет решения всех 136 терминальных задач
  через реальный движок симулятора + smoke-тесты логики
- Живой линк: https://simba-iorda.github.io/linux-guide/

## Структура

- `index.html` — главная страница (полноэкранный терминал + onboarding).
- `assets/style.css` — терминальные стили и темы.
- `assets/js/app.js` — главный контроллер: команды, загрузка уроков, состояние.
- `assets/js/terminal-ui.js` — скроллбэк, строка ввода, фокус, автопрокрутка.
- `assets/js/lesson-engine.js` — парсинг урока и последовательное прохождение
  задач/квизов.
- `assets/js/progress.js` — localStorage-прогресс.
- `assets/js/theme.js` — переключение тем.
- `assets/js/simulator.js` — логика терминала.
- `assets/vendor/fonts/fonts.css` + 12 woff2 — JetBrains Mono.
- `assets/vendor/marked.min.js` — локальный парсер Markdown.
- `content/lessons/*.md` — уроки.
- `content/lessons/manifest.json` — модули и порядок уроков.
- `content/cheatsheet.md` — полный справочник.
- `start.sh` — скрипт запуска локального сервера.
- `SPEC.md` — техническое задание (история требований v1→v4).
- `.github/workflows/pages.yml` — деплой на GitHub Pages.
