# Linux за 2 месяца

Локальный интерактивный учебник по основам Linux. Работает офлайн, без сборки, на чистом HTML/CSS/JS.

Курс: 8 модулей × 5 уроков, 40 уроков, ~30 минут в день. Контент основан на шпаргалке [Linux-](https://github.com/justxor/Linux-) (MIT).

## Как запустить

Сайт работает только через HTTP (fetch не умеет `file://`). Самый простой способ:

```bash
./start.sh
```

Или вручную:

```bash
python3 -m http.server 8000 -d ~/linux-tutorial
```

После запуска открой в браузере:

```
http://localhost:8000
```

## Возможности v3

- **Весь сайт — как терминал kitty**: Catppuccin Mocha по умолчанию, JetBrains Mono везде (включая текст уроков), лигатуры, прозрачность ~0.9, отступы 10 px, нет «карточек» и декораций.
- **Навигация — powerline-таббар снизу**: модули, карта курса и справочник как вкладки со скошенными сепараторами; мобильный сайдбар остаётся через `[menu]`.
- **Урок = сессия терминала**: заголовки секций — как `# комментарий`, вывод — как stdout, квизы — как `[?]` с вариантами a)/b)/c).
- **Roadmap как вывод `tree`**: ASCII-дерево модулей и уроков с прогрессом `[####------] 4/40`.
- **Онбординг как login-секвенция**: `login: user`, `password:`, `Welcome...`.
- **Симулятор терминала**: встроен в тот же терминальный стиль, режимы bash/fish/zsh, ghost-автоподсказка в fish.
- **8 тем**: Catppuccin Mocha/Macchiato/Frappé/Latte, Dracula, Nord, Gruvbox Dark, Tokyo Night — переключатель в правой части таббара.

## Структура

- `index.html` — главная страница (окно kitty).
- `assets/style.css` — терминальные стили и темы.
- `assets/js/*.js` — логика: приложение, рендер, квизы, терминал, прогресс, темы.
- `assets/vendor/fonts/fonts.css` + 12 woff2 — JetBrains Mono.
- `assets/vendor/marked.min.js` — локальный парсер Markdown.
- `content/lessons/*.md` — уроки (отдельная дорожка).
- `content/lessons/manifest.json` — модули и порядок уроков.
- `content/cheatsheet.md` — полный справочник.
- `start.sh` — скрипт запуска локального сервера.
- `SPEC.md` — техническое задание.
