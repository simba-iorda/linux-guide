# Linux за 2 месяца

Локальный интерактивный учебник по основам Linux. Работает офлайн, без сборки, на чистом HTML/CSS/JS.

Курс: 8 модулей × 5 уроков, 40 уроков, ~30 минут в день. Контент основан на шпаргалке [Linux-](https://github.com/justxor/Linux-) (MIT).

## Как запустить

Сайт работает только через HTTP (fetch не умеет `file://`). Самый простой способ:

```bash
./start.sh
```

Или вручную:

```bash
python3 -m http.server 8000 -d ~/linux-tutorial
```

После запуска открой в браузере:

```
http://localhost:8000
```

## Возможности v4

- **Один полноэкранный терминал kitty**: Catppuccin Mocha по умолчанию, JetBrains Mono везде, лигатуры, лёгкая прозрачность, отступы 10 px. Весь интерфейс — строки вывода в едином скроллбэке.
- **Навигация командами**: `помощь`, `курс`, `урок <номер>`, `дальше`, `назад`, `тема список|<имя>`, `shell bash|fish|zsh`, `сброс`.
- **Урок = сессия терминала**: заголовки секций — как `# комментарий`, текст — как stdout, код-блоки — терминальные строки. Каждый новый урок печатается снизу от предыдущего.
- **Квизы в том же промпте**: `[?] вопрос` с вариантами `a)`, `b)`, `c)`; ответ — буква в общей командной строке; верно/неверно + объяснение.
- **Terminal-задачи в том же промпте**: `# задача: …`, команды уходят в симулятор, проверки после каждой команды, успех — строка `Задача выполнено ✓`. Команды `подсказка` и `решение` печатают подсказку и решение.
- **Прогресс и темы** сохраняются в `localStorage`.
- **Онбординг как login-секвенция**: посимвольная печать `login: user`, `password:`, `Welcome...`, кнопка «Погнали». При повторном визите — краткое приветствие и предложение продолжить.
- **Симулятор терминала**: режимы bash/fish/zsh, ghost-автоподсказка в fish, история команд, автодополнение по Tab.
- **8 тем**: Catppuccin Mocha/Macchiato/Frappé/Latte, Dracula, Nord, Gruvbox Dark, Tokyo Night — переключение через команду `тема`.

## Структура

- `index.html` — главная страница (полноэкранный терминал + onboarding).
- `assets/style.css` — терминальные стили и темы.
- `assets/js/app.js` — главный контроллер: команды, загрузка уроков, состояние.
- `assets/js/terminal-ui.js` — скроллбэк, строка ввода, фокус, автопрокрутка.
- `assets/js/lesson-engine.js` — парсинг урока и последовательное прохождение задач/квизов.
- `assets/js/progress.js` — localStorage-прогресс.
- `assets/js/theme.js` — переключение тем.
- `assets/js/simulator.js` — логика терминала (не меняется).
- `assets/vendor/fonts/fonts.css` + 12 woff2 — JetBrains Mono.
- `assets/vendor/marked.min.js` — локальный парсер Markdown.
- `content/lessons/*.md` — уроки (отдельная дорожка).
- `content/lessons/manifest.json` — модули и порядок уроков.
- `content/cheatsheet.md` — полный справочник.
- `start.sh` — скрипт запуска локального сервера.
- `SPEC.md` — техническое задание.
